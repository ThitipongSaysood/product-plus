## A. REST API (NestJS, global prefix `/api`)
Errors: `{ error: "<dict key>" }` with proper status. Auth: cookie `pp_session` = HMAC-SHA256(APP_PASSWORD, "pp-session-v1") hex. APP_PASSWORD unset → open.
Public (no cookie): `/api/health` `/api/auth` `/api/webhooks/apify?secret=` `/api/cron/*` (Bearer CRON_SECRET; unset → allowed only when NODE_ENV!=production) `/api/media/:id`.

6. Review (code-review) → fix → report.
7. Paid steps (smoke 5×4, first 50×4) — **wait for user**.
