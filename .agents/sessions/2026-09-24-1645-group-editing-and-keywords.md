## 17:05 — ตารางกลุ่ม: ปุ่มลบตกบรรทัด

## 17:09 — บทเรียนที่แพงที่สุดของ session: คีย์เวิร์ดภาษาอังกฤษบนเว็บจีน

**เกิดอะไรขึ้น:** ผู้ใช้ตั้งคีย์เวิร์ด `Tempered Glass` ทั้ง 4 แพลตฟอร์ม แล้วกดดึงข้อมูล
ผมเตือนไว้ก่อนแล้วว่าเว็บจีนน่าจะได้ **ศูนย์รายการ** — **ผมเตือนถูกเรื่อง แต่ทำนายผลผิด**

**สิ่งที่เกิดจริง — วัดแล้ว:**

| | |
| --- | --- |
| ดึงมาได้ | 150 รายการ (1688 50 · temu 50 · xhs 50 · **douyin 0**) |
| เป็นสินค้านาฬิกา | **0 จาก 150** (จับด้วย `title ~* 'watch\|手表\|表带\|iwatch'`) |
| ได้อะไรมาแทน | 1688/Temu = ฟิล์มมือถือ (iPhone, Xiaomi) · **XHS = กระจกนิรภัยปูโต๊ะร้านอาหาร** และอุปกรณ์ DIY ลูกปัด |
| ค่าใช้จ่าย | ≈ $1.46 ดึงข้อมูล + $0.59 วิเคราะห์ = **≈ $2.05 ทิ้ง** |

**Why มันแย่กว่าได้ศูนย์รายการ:** รอบที่ได้ 0 แถวจะเห็นทันทีว่าพัง แต่รอบนี้ **"สำเร็จ" ครบทุกตัวเลข** —
150 สินค้า รายงานวิเคราะห์ 10 รายการพร้อมคะแนน 78–99 ทุกอย่างดูปกติทั้งที่วิเคราะห์ของผิดหมวดทั้งหมด

**Learned → บันทึกเป็นกติกาถาวรใน `.agents/AGENTS.md` แล้ว:** คีย์เวิร์ดต้องเป็นภาษาของแพลตฟอร์มนั้น ·
**จำนวนแถวไม่ใช่ความเกี่ยวข้อง** ต้องดูชื่อสินค้าก่อนเชื่อรอบแรกของคีย์เวิร์ดใหม่

**Next:** เปลี่ยนคีย์เวิร์ดเป็น `苹果手表钢化膜` / `苹果手表保护膜` (1688 · Douyin · XHS) และ
